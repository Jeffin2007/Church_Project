## Image Specs

| Use              | Format     | Size            | Notes                                        |
| ---------------- | ---------- | --------------- | -------------------------------------------- |
| Hero background  | JPG / WebP | 1920×1080+      | Landscape, well-lit altar or church interior |
| Section photos   | JPG / WebP | 1600×1200       | Clear, bright                                |
| Timeline cards   | JPG        | 1200×675 (16:9) | Historical / current parish life             |
| Ministry cards   | JPG        | 1200×675 (16:9) | Action shots of ministry members             |
| Gallery (wide)   | JPG        | 1200×900 (4:3)  | Community, Mass, events                      |
| Gallery (tall)   | JPG        | 900×1200 (3:4)  | Processions, portraits                       |
| Priest portrait  | JPG        | 800×1200 (2:3)  | Formal, neutral background                   |
| Feast procession | JPG        | 1920×1080       | Vibrant, many people                         |
| Logo             | PNG        | 512×512         | Transparent background                       |
| Open Graph       | JPG        | 1200×630        | Social media preview                         |
| Favicons / PWA   | PNG / ICO  | 192, 512        | Square, no padding                           |

## Quick Tips

- **Compress before uploading** — use [Squoosh](https://squoosh.app) or [TinyJPG](https://tinyjpg.com)
- **Prefer WebP** over JPG where possible (smaller file, same quality)
- **Keep filenames lowercase** with hyphens — no spaces, no Tamil characters in filenames
- **Minimum quality** — JPG at 80% quality, WebP at 75%
- **Avoid dark / blurry photos** — the website uses images as large backgrounds
